RTKino

v1.0.0 — LOLIN S3 Pro

Flash RTKino firmware directly from your browser.
No installation required.

Your browser does not support Web Serial.
Please use Google Chrome, Edge, or Brave on desktop.
Web Serial is blocked. Make sure this page is served over HTTPS.

How to flash

1
Connect the ESP32-S3 to your computer with a USB-C data cable
2
Click "Install RTKino" above and select the serial port
3
Wait for completion (~60 sec). RTKino will restart automatically.

After flashing — First setup

4
RTKino creates its own WiFi access point. Connect from your phone or laptop:
Network (SSID) rtkino_AP
Password rtkino_zedf9p
Web interface 192.168.4.1
5
From the RTKino web interface, configure your WiFi network and NTRIP caster credentials to start receiving RTK corrections
ZED-F9P configuration required. The u-blox ZED-F9P must be configured before use with RTKino. Load the provided configuration file using u-center and save to flash (UBX-CFG-CFG → Save). See the full setup guide for step-by-step instructions.

Port not showing up? Hold BOOT, press RESET, release BOOT.
On Linux: sudo usermod -a -G dialout $USER
